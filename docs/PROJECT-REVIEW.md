# TBD Care Project Review

تاريخ المراجعة: 28 سبتمبر 2026.

## النتيجة

المشروع مبني بهيكل واضح ويستخدم Server Components و`next/image` بصورة
صحيحة عمومًا. أهم مشكلة كانت تراكم CSS وأصول صور من نسخ سابقة للواجهة،
إضافة إلى خطأ ESLint في إدارة قائمة الهيدر. تم تنظيف هذه الأجزاء مع الحفاظ
على التصميم الحالي بالعربية والإنجليزية.

## ما تم إصلاحه

- حذف مكونات غير مستخدمة: About وProviderCard وGlowingCard وCard UI.
- حذف CSS قديم لتخطيطات لم تعد موجودة، و24+ keyframe غير مستخدم.
- تقليص `story.css` من نحو 4200 سطر إلى نحو 3100 سطر وتنظيم تعليقاته.
- حذف الحزم غير المستخدمة: `@base-ui/react` و`cn` و`shadcn` و
  `tw-animate-css` و`class-variance-authority`.
- إصلاح خطأ `react-hooks/set-state-in-effect` في قائمة الهيدر.
- تأخير تهيئة GSAP إلى `useEffect` لإزالة تحذير hydration على الرئيسية.
- استبدال ألوان متكررة في دليل المزودين بـ design tokens.
- إزالة tokens وتصديرات مكررة أو غير مستخدمة، منها `--primary-soft`.
- حذف مفاتيح `about` و`/#about` بعد إزالة القسم من الصفحة الرئيسية.
- إضافة تعليقات إنجليزية مختصرة للمكونات وملفات الحركة وسكاشن CSS.
- تحويل جميع صور الموقع المستخدمة إلى WebP وتحديد `sizes` للصور الكبيرة.
- إزالة أكبر صورة غير مستخدمة وأصول Create Next App الافتراضية.
- تحديث README وتخطيط الموقع ليطابقا الكود الحالي.

## أثر الصور

- الحجم قبل التنظيف: `10,405,309` بايت للصور الأصلية، متضمنًا أصلًا غير
  مستخدم.
- الحجم بعد التنظيف: `399,800` بايت لصور WebP المستخدمة.

- لا توجد عناصر `<img>` مباشرة؛ الصور تمر عبر `next/image`.

## نقاط تحتاج معالجة لاحقًا

### أولوية عالية

1. **النماذج لا ترسل البيانات**
   - `JoinForm` يحاكي التحميل والنجاح داخل المتصفح فقط.
   - يجب تنفيذ endpoint آمن، تحقق خادمي، حماية من الرسائل المزعجة، وحالة
     خطأ واضحة. العقد المقترح موجود في `docs/api/README.md`.

2. **دليل المزودين تجريبي**
   - البحث والتصفية يعملان على بيانات ثابتة محملة في الصفحة.
   - عند توفر backend، يفضل نقل البحث والصفحات إلى API مع cache مناسب.

### أولوية متوسطة

3. **لا توجد اختبارات آلية أو CI**
   - لا توجد اختبارات وحدات أو مكونات أو تدفقات متصفح.
   - الحد الأدنى المقترح: CI يشغل ESLint وTypeScript و`next build`، ثم
     اختبارات لتبديل اللغة والقائمة والنماذج ودليل المزودين.

4. **Metadata اجتماعية محدودة**
   - `layout.tsx` يحدد العنوان والوصف فقط.
   - يفضل إضافة `metadataBase` وOpen Graph وTwitter image ورابط canonical
     قبل الإطلاق العام.

5. **ملف CSS الرئيسي ما زال كبيرًا**
   - أصبح أنظف لكنه يجمع الرئيسية والهيدر والفوتر وحركتي CSS وGSAP.
   - يمكن تقسيمه مستقبلًا حسب القسم، بشرط الحفاظ على ترتيب cascade وإجراء
     مقارنة بصرية.

### أولوية منخفضة

6. **مساران للمساعد `cn`**
   - `src/lib/cn.ts` يعيد تصدير `src/lib/utils.ts` فقط.
   - يمكن توحيد الاستيرادات وحذف re-export في تغيير ميكانيكي مستقل.

7. **مساران لعرض الشعار**
   - الهيدر يستخدم WebP، والفوتر يستخدم SVG React.
   - هذا مقبول، لكن يفضل تحديد مصدر علامة تجارية واحد عند تثبيت الهوية.

8. **سكريبت تجهيز الصورة غير قابل للنقل بالكامل**
   - `scripts/cutout-doctors.py` يشير إلى ملف مصدر محلي خارج المستودع.
   - يجب تمرير source وdestination كوسائط إذا كان سيستخدم ضمن workflow.

## ملاحظات صحيحة وليست أخطاء

- النص العربي في `ar.ts` وحقول `name.ar` و`address.ar` محتوى واجهة وليس
  تعليقات، لذلك لم يُحذف.
- وجود CSS fallback للحركة مقصود عند غياب GSAP؛ لم يحذف الجزء النشط منه.
- صور شاشات التطبيق ذات `alt=""` داخل عنصر `aria-hidden` صور زخرفية، وهذا
  سلوك وصول صحيح.

## بوابات الجودة

ينبغي أن تبقى الأوامر التالية ناجحة قبل الدمج أو النشر:

```bash
npm run lint
npx tsc --noEmit
npm run build
```

كما يجب فحص الرئيسية بالعربية والإنجليزية على سطح المكتب والجوال ومع
`prefers-reduced-motion`.
